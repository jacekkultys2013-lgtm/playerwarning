Player Warning - mod Fabric na Minecraft 1.21.4 (tylko klient)

Budowanie lokalnie: zainstaluj JDK 21 i Gradle 8.12, potem uruchom "gradle build".
Gotowy plik: build/libs/playerwarning-1.0.0.jar (NIE ten z "-sources").
Wymaga Fabric Loader + Fabric API w folderze mods.

Budowanie bez instalowania czegokolwiek: wrzuc ten folder na GitHub,
zakladka Actions -> build -> Artifacts -> playerwarning-mod.
